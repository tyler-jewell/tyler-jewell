# docs/lsp — LSP policy notes

Agents updating language inventory or LSP config for trees under the umbrella must keep this aligned with sacred **rule 13**.

## Rules

1. Every tree with `AGENTS.md` that holds code declares languages + public LSP names.
2. No language without a public LSP.
3. Agents use LSP when coding; no suppression-as-fix; root-cause resolution.
4. Dual-write `README.md` when this guide changes.
